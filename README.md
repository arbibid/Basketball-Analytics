MelBet WNBA Algorithmic Betting Bot 🏀🤖
Автоматизированная система для поиска валуйных ставок (Value Bets) на матчи женской НБА (WNBA). Бот собирает продвинутую статистику, рассчитывает математическое ожидание исходов и сопоставляет их с букмекерскими линиями (Fonbet/Melbet) в реальном времени.

⚙️ Стек технологий
Язык: Python 3.13

Скрапинг и парсинг: Playwright, Requests/BeautifulSoup

Анализ данных: Pandas, NumPy

База данных: SQLite3

Архитектура: Модульная система с асинхронными демонами

🚀 Основной функционал
Ежедневный сбор данных: Автоматическая загрузка boxscores и play-by-play статистики.

Анализ линий: Поиск расхождений (валуев) между нашей вероятностью и коэффициентами букмекера.

Бэктестинг: Проверка успешности математической модели на исторических данных.

🛠 Развертывание и Запуск (Deploy & Run)
Для корректного старта экосистемы сервисов требуется соблюдать строгую последовательность запуска демонов:

1. **Инициализация базы данных и расписания**
Запустите скрипт для первоначального создания схемы БД и заполнения ее базовыми данными.
`python3 data_collectors/wnba_scraper.py`

2. **Запуск фоновых скрейперов (данные и травмы)**
Скрейперы обогащают БД актуальной информацией о травмах и судьях.
`python3 data_collectors/injury_scraper.py`
`python3 data_collectors/daily_referee_scraper.py`

3. **Сбор букмекерских линий**
Синхронизирует коэффициенты Фонбета и рассчитывает движения линий.
`python3 data_collectors/fonbet_daemon.py`

4. **Оркестратор матчей (Ядро бота)**
Следит за статусами матчей, запускает математическую модель и генерирует Value Bets.
`python3 core_daemon.py`

5. **Telegram Бот**
UI для пользователей (Стандарт/VIP) и система уведомлений об изменениях линии.
`python3 telegram_bot/run_bot.py`
